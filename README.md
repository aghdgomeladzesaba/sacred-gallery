
# Sacred Gallery

A responsive digital art gallery celebrating sacred architecture, Orthodox Christian art, and cultural heritage.

Created as a Mobile Web Development project at Pace University.

## About the Project

Sacred Gallery is an interactive website designed to showcase the beauty of sacred art and architecture.

I wanted to create something that felt more like visiting an art exhibition than browsing a regular website. I used a dark background, antique-gold accents, elegant typography, and interactive images to create an immersive experience.

## Features

- Responsive design for mobile and desktop
- Interactive gallery featuring 10 images
- Full-screen image viewing
- Featured artwork section
- Home and About pages
- Navigation menu
- Custom dark-and-gold theme
- Hover effects and smooth transitions

## Technologies Used

- React
- JavaScript
- Vite
- React Router
- Tailwind CSS
- DaisyUI
- HTML and CSS

## Running the Project

Make sure Node.js and npm are installed.

1. Clone or download the repository.
2. Open the project folder.
3. Install dependencies:

    npm ci

4. Start the development server:

    npm run dev

5. Open the local URL shown in the terminal.
